# tiskmister
This project is my little POC in Golang for the 42Lausanne `taskmaster`. 

The goal of this project is to make a simplyfied job control daemon (like [supervisor](https://supervisord.org/)).   

The programm fill take a yaml configuration file.  
The programm hast to be able to:   
- [ ] orchestraite jobs (as child process)  
- [ ] keep track of those process  
- and many other things.
